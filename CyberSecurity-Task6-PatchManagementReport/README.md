### What the report covers
| Section | Content |
|---|---|
| **Introduction** | Definition of patch management and its role in the vulnerability lifecycle |
| **Why patches matter** | How vulnerabilities are discovered, reported (CVEs) and exploited, plus 2 real-world breaches from unpatched systems (WannaCry/EternalBlue, Equifax) |
| **Consequences of not patching** | Data breaches, ransomware, compliance violations, financial penalties (with figures) |
| **Patch management lifecycle** | Discovery → Assessment → Testing → Deployment → Verification |
| **Best practices** | Prioritised 7-step patch management checklist |
| **Challenges** | Legacy systems, downtime, testing, volume — and how to overcome each |
| **Conclusion** | Why patch management is a high-value control |
| **References** | 7 credible sources (NIST SP 800-40, CISA KEV, CVE/NVD, GAO, Microsoft, FIRST/CVSS, IBM) |
